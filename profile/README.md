- The [Abilities page](https://titanatlas.world/abilities/) is now one list: every ability and promise opens in place, in the same table.
- [Titan.Anti-Drift Traction](https://titanatlas.world/tech/adt/) has its own page. It is under qualification and is not yet a shipped guarantee.
- Eleven Titan sites now have an [About page](https://titanatlas.world/about/) with an Email us form.
- Every linked page on [titanatlas.world](https://titanatlas.world/) and [titanatlas.live](https://titanatlas.live/) now carries the Titans signature footer.
- This organization profile now carries the public Atlas updates journal. Entries are added as items are verified.
- Ubuntu 0.1.1 test builds: a folder-permissions defect was found in real-install testing and corrected candidates are under independent verification.
- A full-screen, edition-aware setup experience for Atlas has a working prototype (design preview; not in any build).
- Ubuntu 0.1.1 corrected candidates (Free `ad9575e7`, Lite `3224ff8a`): real `dpkg -i` install + normal-user first run verified on Ubuntu 24.04 — the folder-permissions defect is confirmed fixed (0 unreadable files, app launches). Independent acceptance and mail-flow tests remain open. Free `ad9575e7` has since been published as the local launch beta (owner-directed); Lite `3224ff8a` remains a candidate.
- Ubuntu 0.1.1 bound candidates: Free `ad9575e7` and Lite `3224ff8a` (permissions-repaired repacks of the pinned producer binaries). Real `dpkg -i` install + normal-user launch verified on Ubuntu 24.04; Lite ELF provably embeds the grant-install UI (`titan-family.js` `fc27a33c`, decoded-asset binding). Two broad-tree respins (`3a5b18a5`, `f69eb35a`) were quarantined after independent scan — do not promote. Independent acceptance remains pending.
- Announcement live: TITAN.ATLAS wordmark launch banner (header Technovier font, "FREE Edition available") deployed on the main pages of titanatlas.world, titandigitalengineering.com and synoct.com — all pointing at the public download.
- Connected-mail path: first-run client-file provisioning (option A) implemented and install-tested — packaged Desktop JSON → private `0600` copy, never overwrites. Real credential drop, rebuild, rescan and Google `gmail.modify` registration remain with the named owners.
- Gmail connection: ships only after a real Google OAuth project exists. Registration underway: TitanArray project created, Gmail API enabled, consent screen + Desktop-app client created. The supported scope is exactly `https://www.googleapis.com/auth/gmail.modify` (Gmail REST; no full-mail or IMAP) — that is the scope to declare in Data Access.
- titanatlas.world layout harmonized and verified live: all 15 measured elements — hero, Digital Engineering, time + state sections, editions cards, Explore, footer grid, notices, legal row and the TITANS lockup — rode one 1200px rail at all 11 widths. A later shared-design layer moved the home page and footer to a 1280px column; sub-page alignment regressed (headings 40px off the footer rail at 1440px+) — the two-rule 1280px rail fix was deployed 2026-10-20 (site-consistency.css v20261020-railfix, all 42 pages).
