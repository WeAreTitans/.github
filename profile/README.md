<p align="center"><sub>Newest first. Items link to a live page where there is one. The full journal is on the <a href="https://titanatlas.world/atlas/upgrades/">Atlas Upgrades board</a>.</sub></p>

**19 Oct 2026**
- The [Abilities page](https://titanatlas.world/abilities/) is now one list: every ability and promise opens in place, in the same table.
- [Titan.Anti-Drift Traction](https://titanatlas.world/tech/adt/) has its own page. It is under qualification and is not yet a shipped guarantee.
- Eleven Titan sites now have an [About page](https://titanatlas.world/about/) with an Email us form.
- Every linked page on [titanatlas.world](https://titanatlas.world/) and [titanatlas.live](https://titanatlas.live/) now carries the Titans signature footer.
- This organization profile now carries the public Atlas updates journal. Entries are added as items are verified.
- Ubuntu 0.1.1 test builds: a folder-permissions defect was found in real-install testing and corrected candidates are under independent verification.
- A full-screen, edition-aware setup experience for Atlas has a working prototype (design preview; not in any build).
- Ubuntu 0.1.1 corrected candidates (Free `ad9575e7`, Lite `3224ff8a`): real `dpkg -i` install + normal-user first run verified on Ubuntu 24.04 — the folder-permissions defect is confirmed fixed (0 unreadable files, app launches). Independent acceptance, mail-flow tests and the Lite grant UI remain open; not yet released.
- Ubuntu 0.1.1 bound: Free `3a5b18a5` and Lite `f69eb35a` are the shipped candidate hashes — both rebuilt from one source on one Gmail scope. Real `dpkg -i` install + normal-user launch verified on Ubuntu 24.04; folder-permissions defect fixed (0 unreadable files); Lite carries the grant-install UI (5/5 grant-flow checks). Independent acceptance remains pending; not yet released.
- Gmail connection: ships only after a real Google OAuth project exists. Registration underway: TitanArray project created, Gmail API enabled, consent screen + Desktop-app client created. Both 0.1.1 binaries request `https://mail.google.com/` — that is the scope to declare in Data Access.
- titanatlas.world layout harmonized and verified live: all 15 measured elements — hero, Digital Engineering, time + state sections, editions cards, Explore, footer grid, notices, legal row and the TITANS lockup — ride one 1200px rail at all 11 widths (390–2560px), no sideways scroll.
